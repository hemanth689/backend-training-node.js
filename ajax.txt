AJAX stands for Asynchronous JavaScript And XML.
It can be used to read the data from the web server after page has loaded.
we can update the web page without reloading the page.
By using this we can send the data to the server.
XMLHttpRequest is a built-in object which is used to request the server for modifying the web page.
To send a request to a server, we can use open() and send() methods of XMLHttpRequest object.
