-> Node.js is a tool that runs JavaScript outside the browser, It is on the server side.
-> generally, JavaScript runs in the browser (like Chrome, Firefox), but with Node.js, 
we can use JavaScript to build the backend of websites or apps.

Why Do We Use Node.js?

-> To write backend code using JavaScript.
-> To connect with databases, handle APIs, and build servers.
-> It is very fast and handles many users at once without crashing.

-> Node.js uses JavaScript for backend development.
-> Instead of using different languages for frontend and backend, we can use just JavaScript language for both.

-> It is used for real-time apps like chat apps, APIs, or streaming services.

-> So when one user sends a message, Node.js quickly handles it and sends it to the other person in real time.

What is Node.js?
-> Node.js is a runtime javascript environment where we can run the javascript outside the web browser.
-> It can be used to build the backend servers for our applications or websites.
-> Node.js excels at handling many simultaneous connections and making it perfect for:
Real-time applications (chats, gaming, collaboration tools)
APIs and microservices
Data streaming applications
Command-line tools
Server-side web applications
-> Its non-blocking, event-driven architecture This means it can keep working while waiting for tasks like reading files or talking to a database. This non-blocking behavior lets Node.js handle many requests efficiently.

What Can Node.js Do?
Web Servers: Create fast, scalable network applications
File Operations: Read, write, and manage files on the server
Database Interaction: Work with databases like MongoDB, MySQL, and more
APIs: Build RESTful services and GraphQL APIs
Real-time: Handle WebSockets for live applications
CLI Tools: Create command-line applications
