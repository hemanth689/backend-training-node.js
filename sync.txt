-> The sync() method in Sequelize is used to synchronize your models with your database.
-> which means creating the tables if they don’t exist, or updating them if needed.
-> when we call sequelize.sync() which means we are asking sequelize to make sure our models and 
actual databases are in sync.

User.sync() - This creates the table if it doesn't exist (and does nothing if it already exists)
User.sync({ force: true }) - This creates the table, dropping it first if it already existed
User.sync({ alter: true }) - This checks what is the current state of the table in the database 
(which columns it has, what are their data types, etc), and then performs the necessary changes in the table to make it match the model.

alter: true
    -> Tries to alter existing tables to match models
    -> May cause unexpected schema changes (especially in complex models)

-> force: false (default)
sequelize.sync({ force: false });

    -> Creates tables only if they don't exist
    -> Does not delete or change existing tables
    -> Safe to use in production
    -> Doesn’t handle model changes automatically and it won’t update columns, types, etc.

sequelize.sync().then(() => {
  console.log("Tables created if they didn't exist.");
});

-> While sync() is a very useful tool during development, it is not designed to be used in production and using its alter or force options may lead to data loss.
-> Migrations can be helpful for production safely.
